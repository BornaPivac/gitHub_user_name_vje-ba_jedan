# gitHub_user_name_vje-ba_jedan
**assets** - Sadrži sve izvorne datoteke koje koristite u igri, poput skripti, 3D modela, tekstura, zvučnih zapisa i scena
**library** - Služi kao lokalna predmemorija (cache) za uvezene resurse. Unity pretvara datoteke iz Assets mape u formate optimizirane za rad u editoru i sprema ih ovdje.
**logs** - Sadrži zapise o radu editora, paketima i eventualnim pogreškama koje su se dogodile tijekom izvođenja ili uvoza resursa
**packages** - Sadrži manifest datoteku koja definira sve ovisnosti projekta (npr. Unity UI, Physics, Analytics). Unity Package Manager koristi ovaj direktorij za upravljanje vanjskim modulima i alatima
**ProjectSettings** - Pohranjuje sve postavke projekta koje definirate putem izbornika
**UserSettings** - Sadrži postavke specifične za pojedinog korisnika, poput rasporeda prozora u editoru ili preferencija koje se ne bi trebale dijeliti s ostatkom tima putem sustava za kontrolu verzija
**.vsconfig** - Datoteka koja konfigurira Visual Studio okruženje za konkretan projekt

**.gitignore** - tekstualna datoteka koja govori Git-u koje datoteke ili cijele mape treba zanemariti (ne pratiti) u projektu, služi za sprečavanje
